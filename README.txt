FACE FLAPPY DELUXE - TWO AUDIO EDITION

Files:
- index.html
- background track.m4a  (looping background music)
- hit.mp3               (collision sound)

The game first looks for a local face.png. If it is not present, it automatically
falls back to the supplied Postimg face image URL, so the game can still start.

For a fully self-contained/offline copy, put your background-removed face image
beside index.html and name it exactly face.png.

Deploy the folder contents to Netlify. Do not require a Netlify login for visitors;
use the site's public deploy URL.
